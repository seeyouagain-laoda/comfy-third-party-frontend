# Comfy 第三方前端 第三方依赖说明
# ============================================
# 纯「提示词优化 + 对话」模式：零第三方依赖，Python 标准库即可运行。
#
# 「文生图 / 图生图 / H3 视频」模式需要 comfy-cli（把 ComfyUI 的 UI 工作流转成 API 格式）。
# 装在 ComfyUI 的 venv 里，或你自己的 Python 里都行：
#
#     pip install comfy-cli
#
# 没有 comfy-cli 时，前端「设置 → 依赖自检」会报它缺失，文生图/图生图会失败；
# 但页面本身、对话、提示词优化仍可正常用。
#
# 没有列在 requirements 里的标准库（json/os/...）Python 自带，无需安装。
